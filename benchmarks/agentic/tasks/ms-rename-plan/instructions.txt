The directory /data contains files. Plan a renaming (do not actually
rename anything): order the files by
  1. number of lines, descending
  2. then file size in bytes, ascending
  3. then name, ascending
and number them starting at 01. Write the plan to /plan.txt with one
line per file in that order, formatted exactly as:
oldname -> NN_oldname
followed by a final line exactly:
total_files=N
A trailing newline at the end of a file does not start a new line.
