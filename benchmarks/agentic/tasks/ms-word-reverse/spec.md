# Spec

Transform the text in /message.txt word by word (words are separated by
single spaces; keep them in their original order, separated by single
spaces):

- A word of 3 letters or fewer is copied unchanged.
- A longer word has its letters reversed. If the original word started
  with an uppercase letter, the transformed word must start with an
  uppercase letter and continue in lowercase; otherwise it is all
  lowercase.

Write the result to /out.txt.
