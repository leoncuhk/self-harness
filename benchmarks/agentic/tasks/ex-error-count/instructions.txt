Each line of /logs/app.log has the format:
<timestamp> <LEVEL> <message>
The LEVEL field is the second whitespace-separated token. The message
text may itself contain level words like ERROR or WARN - only the LEVEL
field counts.

Compute two numbers:
  E = lines whose LEVEL is ERROR, excluding lines whose message contains
      'retry scheduled'
  W = lines whose LEVEL is WARN and whose message contains 'disk'

Write /answer.txt containing exactly one line in exactly this format:
errors=E;warnings=W
(for example: errors=7;warnings=2)
