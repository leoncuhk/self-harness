# 05 — Harness 优化分析：直解实验揭示的提升机制（Wave 1）

> 实验：由强模型（本 agent）以**答案感知验证**模式直解 9 题（每类 1 题），全部判据可从一手来源定位/复算。
> 结论先行：**题目所需知识全部公开可得，失分主因是流程与口径，而非知识**。以下每条机制都对应 Wave 1 中实证过的判据命中。

## 一、九题直解的总体结果

- 8/8 数值轨道题 100%（21 个数值类 dealbreaker 全过）；q001（纯定性）自评 9/9 待 LLM 轨道复核
- 平均 3.9 次工具调用/题（官方 harness agent 常见 30-100+ turns）——检索定向性是第一差距
- 逆向出的官方口径约定 7 条（见下表），每条都有判据级证据

## 二、提升机制量化（口径工程 = 最大杠杆）

| # | 机制 | Wave 1 实证 | 影响的判据 | 预期提升点 |
|---|---|---|---|---|
| 1 | **事件窗口口径**（基准=提交日收盘；日历日偏移；顺延） | q007：换任一种合理口径都 miss | q007 的 5 个 MUST（占该题判据 5/8） | 市场分析类整类保命 |
| 2 | **建模 FCFF 口径**（NOPAT+非现金加回+SBC/重组加回−CapEx−ΔNWC） | q025：四种教科书口径 EV 全 miss（206k-226k vs 239,207） | q025 EV（sev2 MUST）+ 全部模型中间值 | 建模类从 0 到有 |
| 3 | **股本口径选择**（封面股本/剔除限制性股票/最新可得） | q010：AER 用含限制性股票股数→P/B 1.31 挂；q015：封面 vs 报表日差 0.12% 足以 miss | q010 4 个 MUST + q015 股权价值 | 可比/先例类高频坑 |
| 4 | **中间值全量陈述**（桥表每行、模型每年、每个比率） | q017/q019/q025 的判据一半以上是中间值 | 239 判据中约 60% 是非最终值 | 全类别普惠 |
| 5 | **结论句显式化**（"X is higher"、"rankings are not the same"） | 几乎每题都有 MUST 结论项 | 79 个 MUST 中约 1/4 是结论句 | dealbreaker 保险 |
| 6 | **检索定向性**（披露措辞做查询词；Ex 99.1 优先；R 文件；20-F 意识） | q024 两条查询直接锁定；q017 一次 fetch 全桥表；q010 AER 只搜 10-K 会空手 | 全部题的时间预算与超时率 | 长题（专家 70-120min）完成率 |
| 7 | **口径漂移防御**（持续经营重述列优先；指引两步中值） | q019：FY24 用重述列 14.88% 而非原口径 12.62% | q019 的 3 个 MUST bps 差 | 财报分析类 |

**量化估算**：Wave 1 的 33 个数值类 MUST 判据中，12 个（36%）完全取决于上述口径约定而非计算能力。由于任一 MUST 挂掉全题归零，仅"口径工程"一项对期望总分的贡献就在**两位数百分点**量级（对照官方榜首 60.6%）。

## 三、直解 vs 官方 harness 的差距解剖

| 维度 | 直解（本研究） | 官方 harness 默认 | 优化方向 |
|---|---|---|---|
| 检索 | 用披露短语+表型+日期一步命中 | 模型自由发挥，常多轮试探 | SYSTEM_PROMPT_V2 检索策略节 |
| 取数 | R 文件/Ex99.1/定向 grep | 全文 parse 后整段 retrieve | 教 agent 优先小而准的文档 |
| 计算 | 每步必算、不rounding中间值 | 模型常心算/早round | 计算纪律条款 |
| 表述 | 判据友好（平实、全量、显式结论） | 自然叙述，漏中间值/结论 | 表述规范条款 |
| 抗遗忘 | 随手记工作笔记 | 上下文溢出丢最旧历史 | 笔记条款 + 防截断 |
| 长题管理 | 先列清单再动手 | 易超时 | 计划条款 |

## 四、SYSTEM_PROMPT V2 与验证计划

`SYSTEM_PROMPT_V2.md` 已按上表七条机制写成可直接替换的体系提示（只含通用约定，无题目特定信息，可迁移到未见题）。

**验证设计（API key 到位后执行）**：
1. A/B：同一模型（建议 2 个头部模型各跑）× {官方原 prompt, V2 prompt} × 27 题 × 3 次
2. 主指标：Partial Credit（LLM 轨道补全后）；分层指标：dealbreaker 通过率、数值判据命中率、超时率、turn 数
3. 判定：V2 若在 dealbreaker 通过率上 +10pp 以上即为有效，逐条机制归因（对照上表）
4. 防过拟合：V2 的条款必须全部来自"通用约定"论证，Wave 2/3（其余 18 题）作 held-out 验证

## 五、诚实性声明

- 直解是**答案感知**的（见过 rubric），100% 不能外推为"模型裸跑可得 100%"——它的意义是证明了**上限可达**与**路径可教**。
- 真实基线必须等官方 harness + API key 的盲测；V2 的净效应也以该盲测为准。
- 本文档所有口径结论均有 solutions/ 下的一手来源引用支撑，可复核。
