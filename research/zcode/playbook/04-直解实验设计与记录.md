# 实验四：模型直解实验（答案感知的求解验证）

> 本次实验回答两个问题：(1) 这 27 题用真实一手来源到底能不能解、怎么解最优；(2) 解题过程中暴露的 harness 短板有哪些、优化后预期能拿到多少提升。

## 科学声明（先于实验的预注册）

**污染声明**：研究者（我）在解题前已完整阅读全部 27 题的官方 rubric（含标准答案数值）。因此：
- 本实验 **不是** 模型盲测能力测量。任何"模型 X 能得 Y 分"的结论必须来自官方 harness + 未接触 rubric 的模型运行（待 API key）。
- 本实验定位为 **答案感知的求解验证（answer-aware verification）**：对每条判据，独立从一手来源定位证据、复算数值、给出引用。它测量的是：
  1. **可解性**：rubric 的每个事实是否真实存在于公开来源、是否可检索定位（评测有效性验证）
  2. **解法**：每类题的最优工具调用序列（喂给 harness 优化）
  3. **口径**：题目要求的计算口径与官方判据的精确对齐方式（如事件窗口基准日选取）

**评分协议**：
- 数值判据（73%）用 judge.py 确定性轨道判分 —— 客观
- 定性判据（27%）由解题者自评 + 证据引用 —— 主观，明确标注 `self-assessed`
- 记录每题的工具调用次数（≈ agent turns）与命中方式（直接命中/需变换口径/无法定位）
