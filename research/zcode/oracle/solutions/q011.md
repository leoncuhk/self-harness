# q011 — Comparables：TGT vs WMT 固定费用保障倍数（FCCR）

**题目**：FY 截至 2025-02-01（TGT）/ 2025-01-31（WMT），FCCR = EBITDAR /（利息费用 + 固定经营租赁成本）；租金加回用剔除短期与变动部分的经营租赁成本（WMT 已告知 = $2,347M）。

## 研究过程（4 次工具调用）
1. WMT 10-K（`wmt-20250131.htm`，2025-03-14）：OI **$29,348M**、现金流量表 D&A **$12,973M**、ROI 表 "Rent" **$2,347M**、Interest, net **$2,245M**（Debt 2,249 − 利息收入 483 + 融资租赁 479）
2. TGT 10-K（`tgt-20250201.htm`，2025-03-12）：OI **$5,566M**、现金流量表 D&A **$2,981M**、租赁附注经营租赁成本 $641M − 脚注短期/变动 $132M = **固定 $509M**、Net interest expense **$411M**

## 计算（8/8 判据命中，含 3 个 MUST）
| | TGT | WMT |
|---|---|---|
| EBITDAR = OI+D&A+固定租金 | 5,566+2,981+509 = **$9,056M** | 29,348+12,973+2,347 = **$44,668M** |
| 固定费用 = 利息+固定租金 | 411+509 = **$920M** | 2,245+2,347 = **$4,592M** |
| FCCR | 9,056/920 = **9.84x** (MUST) | 44,668/4,592 = **9.73x** (MUST) |

**TGT 保障倍数更强，约高 0.12x turns**（9.8435−9.7275=0.1160）。

## 最终提交（benchmark 格式）
For fiscal 2025 (Target's year ended February 1, 2025; Walmart's year ended January 31, 2025): Target EBITDAR = operating income $5,566M + depreciation and amortization $2,981M (cash flow statement) + fixed operating lease cost $509M (operating lease cost $641M less $132M of short-term and variable lease costs) = approximately $9,056 million. Target total fixed charges = net interest expense $411M + fixed operating lease cost $509M = approximately $920 million, giving FCCR ≈ 9,056/920 = 9.84x. Walmart EBITDAR = operating income $29,348M + D&A $12,973M + fixed operating lease cost $2,347M (net of variable and short-term components) = approximately $44,668 million. Walmart total fixed charges = interest, net $2,245M + fixed lease $2,347M = approximately $4,592 million, giving FCCR ≈ 44,668/4,592 = 9.73x. Target demonstrates the stronger fixed charge coverage, by approximately 0.12x turns (9.84x vs 9.73x).

## Harness 观察
1. **D&A 取现金流量表口径**（含计入销货成本的部分），不是利润表的 "exclusive of depreciation in cost of sales" 行——TGT 两行差 $452M，用错 FCCR 变 9.29x，MUST 全挂。
2. **利息用"净利息"口径**（两家都是 Income statement 的 net interest / Interest, net），WMT 若用 Debt-only 2,249 会得 4,596 ≠ 4,592。
3. **固定租金 = 经营租赁成本 − 短期/变动部分**：TGT 要读附注脚注 (a)（$132M）；WMT 的 $2,347M 藏在 10-K 自己的 ROI 计算表 "Rent" 行——**目标公司的自定义非 GAAP 表常常就是判据口径的出处**，优先找。
